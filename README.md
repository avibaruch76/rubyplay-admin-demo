# RubyPlay Admin — UX Demo

Interactive UX prototype for the RubyPlay multi-studio admin.

- 6 studios (Ruby Play · Koala Games · Mad Hat · Spincraft · Firerose · X Slots)
- 756 games pulled from the operational portfolio sheet
- Games · Studios · Series · Themes · Releases · Media · Translations · News
- Public site composer (Group homepage · Pages · Navigation · Footer)
- Users & roles with 39-permission matrix
- Live page previews

This is a static HTML prototype — no backend, no database. Click around to explore.

## Local development

Just open `index.html` in a browser. No build step.

## Deployment

Deployed on Render as a static site. Pushing to `main` auto-deploys.

`render.yaml` configures the static site service.
